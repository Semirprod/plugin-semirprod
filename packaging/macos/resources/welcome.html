Semirprod pour OBS

Cet installeur pose le plugin dans ton dossier utilisateur. Aucun mot de passe administrateur n'est demandé, et rien n'est modifié dans OBS lui-même.

Ferme OBS avant de continuer. S'il est ouvert, l'installation réussira quand même, mais le plugin ne sera actif qu'au prochain démarrage d'OBS.

Il te faut :

  • OBS Studio 32.0 ou plus récent
  • macOS 13 ou plus récent

Installation dans ~/Library/Application Support/obs-studio/plugins/ — le seul emplacement qu'OBS examine sur les Mac Apple Silicon.
